# ATSRS video production

For every new ATSRS video, produce paired dark and light editions from the same source timeline. Keep script, audio, scene durations, cuts, motion, layout and content identical; change theme colours and embedded ATSRS UI surfaces only. Preserve external employer website colours and brand assets. Never overwrite the original master. Export both posters and MP4s, verify equal frame counts and audio, and select the edition from the homepage theme. Do not advertise unreleased features as available. Keep private profile information out of public videos.
