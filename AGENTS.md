# ATSRS video production

For every new ATSRS video, produce paired dark and light editions from the same source timeline. Keep script, audio, scene durations, cuts, motion, layout and content identical; change theme colours and embedded ATSRS UI surfaces only. Preserve non-green employer/brand colours; in light editions the owner requires every green element to be blue. Never overwrite the original master. Export both posters and MP4s, verify equal frame counts and audio, and select the edition from the homepage theme. Do not advertise unreleased features as available. Keep private profile information out of public videos.

Theme palette: dark mode uses green accents; light mode uses blue #167bd3 (strong #0b5ca8), navy text #0b2554 and muted text #536680. Apply this inside video graphics and embedded ATSRS UI, not only the surrounding player. In light videos, all green elements must become blue, including success/status icons. Keep non-green warning/error colours.
